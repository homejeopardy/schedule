Weekly schedule maker

How this works

This makes printable weekly schedules — class timetables, work rotas, practice plans, family calendars. Click Edit schedule to change anything. Everything is saved in your browser automatically; Save file / Load file back it up or move it between computers as a small .json file.

  • Schedules — independent tabs (here, one per grade). Add as many as you like; each has its own events and menus.
  • Events have a day, start and end times, a title, and optional detail (person) and location. Times are H:MM — write 1:27 for afternoon, or use 24-hour / am-pm forms. Breaks are thin labeled gaps (Lunch, Travel, …).
  • Choice menus are for schedules that vary by person: define a menu (say, sections B, P, C, or shifts Early, Late) and any event can “vary by” it, with different content per option. The menus appear in the top bar, so one schedule prints correctly for everyone once they pick their options. Skip this entirely for a simple schedule.
  • The week grid's time axis sizes itself to your earliest and latest events, and Saturday/Sunday columns appear only if you use them. No two events in one schedule may overlap in time.
