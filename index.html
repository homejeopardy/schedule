How to make a custom schedule CSV (Google Sheets)

Build a sheet with these ten columns in row 1, then File → Download → Comma Separated Values (.csv) and import it here. Click Example CSV to download the built-in schedule in this exact format — the easiest way is to import that into Sheets and edit it.

Type, Grade, Day, Start, End, Block, Split, Subject, Teacher, Room

Every class and break carries its own Start and End time, so each day can have any bell schedule you like. Times are H:MM — write 1:27 for afternoon, or use 24-hour (13:27) / am-pm (1:27 pm) forms; bare times before 8:00 are read as PM. The week-grid time axis sizes itself to your earliest and latest times.

There are four row types:

  • class — one row per grade + day + time slot + split.
    • Grade: any label (6, 7, 8, …). Each distinct value becomes an option in the Grade menu.
    • Day: Mon, Tue, Wed, Thu, Fri (full names also work).
    • Block: which chooser applies — 1 (1-block menu), 2 (2-block menu), L (language menu; if a grade has any L rows its second menu is labeled “Language block”), or x (whole grade together — leave Split blank, one row covers everyone).
    • Split: the section groups within a grade — any short labels you like (B/P/C, Red/Blue, 1/2/3/4, …), and any number of them. A grade's split menus are built from the labels its class rows use, in first-appearance order. Rows with the same grade, day, times, and block are one slot, and every non-x slot needs one row per split label used in that grade.
    • Teacher: initials (looked up in the name rows) or a full name. Multiple teachers: MP, SR.
    • A x row with Subject Advisory and blank Teacher/Room fills in from the Advisor menu.
  • break — Grade, Day, Start, End, and a label in Subject (Break, Lunch, …). Rendered as a small label in the grid and a thin row on day cards.
  • advisor — one row per advisor: Grade, Teacher (initials), Room. These populate the Advisor menu.
  • name — maps initials to display names: full name in Subject, initials in Teacher.

Leave unused cells blank. No two classes or breaks in the same grade + day may overlap in time (every student attends every slot). Subjects named “Office hours” hide their teacher/room details, matching the built-in behavior. Imported schedules are remembered until you click Built-in.
